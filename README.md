# Digital Bank Landing Page

A responsive digital banking landing page built as a Frontend Mentor challenge.

## Features

* Responsive navigation
* Hero section
* Banking services section
* Latest articles section
* Call-to-action sections
* Responsive design for different screen sizes

## Technologies

* HTML
* CSS
* JavaScript

## Purpose

This project was built to practice responsive layouts, landing page structure, navigation, reusable UI sections, and modern web design.
